Wind-Up Minds · 03A Tiny Network, Learning

Orange dots and blue dots. A small neural network has to learn which side of the board belongs to which color. The background is its current guess, redrawn every step as it learns.

The engine is about 120 lines of plain Python, with no numpy and no torch. It runs right here in your browser on Pyodide, a build of Python compiled to WebAssembly. Every number remembers where it came from, so when the guess is wrong, the blame flows backward and each weight nudges itself.
